# 开机资源加载优化提高开机速度
修改ZygoteInit.java中的预加载资源函数
1. preload()
```java
 static void preload(){
     Thread preloadRsThread = new Thread(new Runnable(){
         @Override
         public void run(){
             //将加载资源函数放子线程，加载资源文件比加载classes文件要快，
             //因此这里不提示子线程优先级
             preloadResources();
         }
     });
    //启动资源加载子线程
     preloadRsThread.start();

     preloadClasses();

     //等待资源加载子线程完成
     try{
         preloadRsThread.join();
     }catch(InterruptedException e){
         e.printStackTrace();
     }
 }
```

2. 在preloadClasses中减少gc频率
```java
private static final int PRELOAD_GC_THRESHOLD = 4*1024*1024;//default is 50000
 private static void preloadClassed(){
     final VMRuntime runtime = VMRuntime.getRuntime();
     int count;

     Class.forName(line);
     if (count%128 == 0 && Debug.getGlobalAllocSize() > PRELOAD_GC_THRESHOLD){
         if (false){
             Log.v(TAG,"GC at"+Debug.getGlobalAllocSize());
         }
        System.gc();
        runtime.runFinalizationSync();
        Debug.resetGlobalAllocSize();
     }
     count++;

 }
```
3. 设置ZygoteInit.main的线程优先级
```java
    public static void main(String argv[]){

        try{
            //优化开机速度begin
            //获取当前线程优先级
            int currentPriority = Process.getThreadPriority(Process.myPid());
            Process.setThreadPriority(Process.THREAD_PRIORITY_AUDIO);//priority -16
            //add end

            //startprofiling the zygot initialization
            SamplingProfilerInteration.start();
            //...

            //加载资源
            preload();

             SamplingProfilerInteration.writeZygoteSnapshot();

            // Do an initial gc to clean up after startup
            gcAndFinalize();

            //add begin restore Thread Priority
            Process.setThreadPriority(currentPriority);
            //add end

        }
    }
```
