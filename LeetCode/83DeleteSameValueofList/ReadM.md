# 题目
给定一个已排序的链表的头 head ， 删除所有重复的元素，使每个元素只出现一次 。返回 已排序的链表。
1. 链表中节点数目在范围 [0, 300] 内
2. -100 <= Node.val <= 100
3. 题目数据保证链表已经按升序 排列
# 思路
重复的元素出现的位置是连续的。
1. 从指针指向链表的头节点，随后对链表遍历。
2. 如当前cur与cur.next对应的元素相同，则将cur.next移除
3. 否则说明链表中不存在与cur对应的元素相同的节点，因此可以将cur指向cur.next
4. 遍历完整个链表后，返回链表的头节点即可
# 细节
遍历最后一个节点时候，cur.next为空节点，会产生运行错误。因此只需要遍历到链表最后一个节点，而不是遍历完整个链表。
