# 简介
[Website](https://juejin.im/post/5a974960f265da4e7071f9ec)

**定义** 一块缓存了一定线程数量的区域
### 作用
1. 重用线程
2. 控制线程池的最大并发数
3. 管理线程（统一分配，调优，监控）
### 有点
1. 降低因线程的创建销毁所带来的性能开销
2. 重用缓存在线程池的线程
3. 提高线程相应速度和执行效率
4. 提高对线程的管理度
注：传统的多线程方式（继承Thread类&实现Runnable接口）的问题
1.每次新建销毁线程对象消耗资源响应速度慢
2.线程缺乏统一管理，容易出现阻塞情况

# 2.工作原理
## 2.1 核心参数
| 参数 | 意义 | 说明 |
| -- | -- | -- |
| corePoolSize | 核心线程数 | 默认情况下，核心线程会一直存活，包括空闲状态 |
| maxmumPoolSize | 线程池所能容纳的最大线程数 | 后续新任务会阻塞 |
| keepAliveTime | 非核心线程超时时长 | 超过该时长，非核心线程回回收；allowCoreThreadTimeout设置为true时对核心线程也起作用 |
| unit | 制定keepAliveTime参数的时间单位 | TimeUnit.SECONEDS等 |
| workQueue | 任务队列 | 通过线程池的execute()方法提交的Runnable对象将存储在该参数中 |
| threadFactory | 线程工厂(是一个接口) | 作用 = 为线程池创建新线程；具体作用=只有1个方法 |

# 2.使用流程
1. 创建线程池
2. 向线程池提交任务：execute();
3. 关闭线程池shutdown();

# 常见的4类功能线程池
* 定长线程池（FixedThreadPool）
* 定时线程池（ScheduledThreadPool ）
* 可缓存线程池（CachedThreadPool）
* 单线程化线程池（SingleThreadExecutor）

## 定常线程池FixedThreadPool
* 特点：只有核心线程不会被回收，线程数量固定，任务队列无大小限制（超出线程任务会在队列中等待）
* 应用场景：控制线程最大并发数
* 具体使用：通过Executors.newFixedThreadPool()创建
## 定时线程池ScheduleThreadPool
* 特点：核心线程数量固定,非核心线程数量无限制（空闲时马上回收）
* 应用场景： 执行定时/周期性任务
* 使用：通过Executors.newScheduledThreadPool()创建
## 可缓存线程池CachedThreadPool
特点：只有非核心线程，线程数不固定，可无限大，灵活回收空闲线程，具备超时机制，全部回收时几乎不占用系统资源；自动新建线程（无线程可用时）
**任何线程任务到来都会立即执行，不需要等待**
* 应用场景：执行大量、耗时少的线程任务
* 使用：同样Executors.newCachedThreadPool()创建
## 单线程化线程池SingleThreadExecutor
* 特点：只有一个核心线程（保证所有任务按照指定顺序在一个线程中执行，不需要处理线程同步的问题
* 应用场景： 不适合并发但可能引起IO阻塞性及影响UI线程响应的操作，如数据库操作，文件操作等
* 使用：通过Executors.newSingleThreadEcecutor()创建
